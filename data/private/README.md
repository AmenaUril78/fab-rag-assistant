# Your private documents go here

Put your own runbooks, SOPs, and troubleshooting notes in this folder
(`.md`, `.txt`, `.pdf`, `.docx`, `.html`; subfolders are fine), then pick
**My documents** in the app sidebar and click **Rebuild index**.

Everything in this folder except this README is listed in `.gitignore`, so it is
never committed or pushed to GitHub.

For work documents, run the app locally with Ollama (see the main README) so
neither the documents nor your questions leave your computer. Check your
organization's data policy before using internal documents with any AI tool.
